Name: frontend-design
Purpose: Guides creation of distinctive, production-grade frontend interfaces that avoid generic "AI slop" aesthetics — real working code with exceptional attention to aesthetic detail.

Design Thinking (before writing any code)
Commit to a bold aesthetic direction by answering:

Purpose — what problem does this solve, who uses it?
Tone — pick an extreme: brutally minimal, maximalist chaos, retro-futuristic, luxury/refined, playful, brutalist, art deco, etc.
Constraints — framework, performance, accessibility
Differentiation — what makes it unforgettable?


Aesthetics Guidelines
Typography — Use beautiful, distinctive fonts. No Arial, Inter, Roboto, or Space Grotesk. Pair a display font with a refined body font.
Color & Theme — Commit to one cohesive palette via CSS variables. Dominant colors + sharp accents beat timid even distributions.
Motion — CSS-only animations preferred for HTML. Focus on high-impact moments: staggered page-load reveals, hover states that surprise. Don't scatter micro-interactions everywhere.
Spatial Composition — Unexpected layouts, asymmetry, overlap, diagonal flow, grid-breaking elements.
Backgrounds & Depth — Gradient meshes, noise textures, geometric patterns, layered transparencies, dramatic shadows — never just a flat solid color.

Hard Rules

Never use generic AI aesthetics (purple-on-white gradients, predictable component patterns, cookie-cutter layouts)
Match implementation complexity to the vision — maximalist = elaborate code, minimalist = restraint and precision
Every design should feel genuinely designed for its specific context, not reused from a template
